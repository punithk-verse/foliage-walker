# foliage-walker
find the best fall-colour trail near you, pick the day, go outside.   Open pieces: OpenStreetMap (Nominatim + Overpass), Open-Meteo, and a local open-weight LLM served by Ollama. No API keys, no accounts. Usage: python foliage_walker.py "Cubbon Park, Bengaluru" --radius 8 --min-km 2
